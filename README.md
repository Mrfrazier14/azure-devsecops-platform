# Azure DevSecOps Platform

**Cloud deployment architecture with security built in**

## Overview

A cloud deployment architecture using GitHub Actions, Docker, Azure, and Terraform, with automated tests, security scanning, logging, and monitoring built in.

## Tech Stack
